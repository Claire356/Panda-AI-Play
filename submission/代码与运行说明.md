# Panda AI Play｜代码与运行说明

**作品名称：Panda AI Play**  
**团队：恭喜发财**  
**主玩法：圣杯拍卖会**  
**源码仓库：** https://github.com/Claire356/Panda-AI-Play

本项目是可在浏览器中交互的 Web 应用。用三份短提案观察用户如何查证、判断和解释原因，再给出暂定人物卡及适合继续完成的一次研究实验。参赛演示使用仓库自带的合成行情，无需注册、登录、API 密钥或付费服务。

## 1. 如何获得源码

从百度网盘下载源码压缩包并完整解压；或在 GitHub 仓库选择 **Code → Download ZIP** 后解压。也可以使用 Git：

```sh
git clone https://github.com/Claire356/Panda-AI-Play.git
cd Panda-AI-Play
```

主要文件：

| 路径 | 内容 |
| --- | --- |
| `dist/index.html` | 网页入口 |
| `dist/app.js` | 游戏交互、行为画像、任务推荐与导出 |
| `dist/engine.js` | 合成行情、研究计算与数据检查 |
| `dist/style.css`、`dist/assets/` | 页面样式、角色与场景素材 |
| `scripts/serve.py` | 本地演示启动程序 |
| `scripts/test.cjs` | 行为规则与计算检查 |
| `DEMO.md` | 简短演示路线 |

## 2. 本地启动：推荐演示方式

准备一台已安装 **Python 3.9 或以上版本** 的电脑，以及支持现代 JavaScript 的 Chrome、Edge、Safari 或 Firefox 浏览器。应用没有前端依赖安装或构建步骤；无需安装 Node.js 即可试玩。

1. 打开终端，进入解压后的项目目录，即同时含有 `dist` 和 `scripts` 的文件夹。
2. 启动本地服务。

macOS / Linux：

```sh
python3 scripts/serve.py
```

Windows：

```powershell
py -3 scripts/serve.py
```

如果 Windows 使用 `python` 命令提供 Python 3，也可以运行 `python scripts/serve.py`。

3. 保持终端开启，在浏览器打开 **http://127.0.0.1:8765/**。
4. 看到“三位商人。你信谁？”及三档玩法入口后，即可开始体验。
5. 演示结束，在终端按 `Ctrl+C` 停止服务。

默认仅监听本机 `127.0.0.1`，使用 HTTP，无需 HTTPS 或登录。这个地址只对启动服务的电脑有效，不是公开在线体验地址。请通过本地 HTTP 地址访问，不要直接双击 `index.html` 代替启动。

## 3. 推荐试玩路线

1. **看开场，选玩法。** 首页直接展示约 20 秒静音场景动画，可暂停、重播；不必等播放结束。入门“带我玩”提供白话线索，中级“我来判断”按需提示，高级“给我挑战”提供原始底稿且三份提案共用三次调查。入口只决定体验方式，不直接评级能力。
2. **连续完成三份提案。** 每份按“查一条记录 → 作判断 → 选一句原因”推进。“留下研究”表示继续研究，“有问题”表示指出疑点，“先等等”可进一步区分证据不足、没看懂或拿不准。选完原因便进入下一份，角色与记录随提案更换；判断按钮保留一致，方便理解操作。
3. **查看人物卡与依据。** 结果展示本局查证方式、观察依据和一个推荐实验。可展开“为什么这样判断？”查看过程记录。使用提示、带练和重复案例会单独记录，未观察到的知识保留未知。
4. **完成下一步实验。** 根据本局表现练习时间顺序、样本验证或结论边界，选择一条研究约束并完成封存。可下载行为档案 JSON、带走人物卡；完整研究台还提供计算与数据导出入口。

首次体验可选“带我玩”。需要展示推荐差异时，用新的隐私窗口分别完成两种路径：一条多次明确表示“我还没看懂”，另一条独立查证时间、样本与费用并选择相应理由。对照人物卡、推荐实验及讲解方式，不以收益高低比较用户能力。

## 4. 断网与现场备份

提前完整下载源码包、解压，并在演示电脑安装 Python 3。上述启动流程不需要联网安装依赖；核心游戏、合成行情、场景与角色素材均随源码提供，可用于断网演示。

页面引用 Google Fonts 的中文字体。断网或字体服务不可用时，浏览器会使用系统字体，字形或排版可能略有变化；游戏与研究计算不依赖该字体服务。Panda Data 文档、GitHub 等外部资源链接需要联网，现场离线演示可不打开。

演示前建议实际断网走通一局，并在本地保留源码包、运行说明和路演 PDF。此包不含 Python 安装程序，需在断网前准备好运行环境。

## 5. 数据、功能与画像边界

- **本次分发包：** 原生 HTML / CSS / JavaScript 应用，内置 40 个合成观察点。页面标注“演示模式 · 合成样本”，报告与实验数字由该数据计算。
- **授权数据：** 本包不含 Panda Data 账号、密码、令牌、授权原始行情或开发者本机登录服务。下载源码不会自动取得数据权限；开发者本机的授权行情接入不属于此分发包的默认启动流程。
- **游戏角色：** 狐狸、松鼠与熊猫为预设教学剧情角色，不是实时生成回复的 AI Agent。首页是浏览器场景动画，不是独立 MP4 演示视频。
- **推荐依据：** 当前按可解释规则结合查证、判断理由、提示与重复记录形成暂定画像和后续任务。它不是心理测量、投资能力评级或真实风险承受力评估；没有宣称真实用户转化率或测评准确率。
- **研究计算：** 正常研究流程使用当时已知信息、日频开盘执行与单边 0.1% 成本；故意读取未来或复用样本的报告用于教学。未模拟滑点、停牌、涨跌停及实际成交限制，不构成生产回测或投资建议。
- **本机记录：** 浏览器只持久保存开场观看、上次玩法、已见题目和完成次数等轻量体验历史；本局行为可主动导出。刷新可能清空本局进度，需保留结果时请先下载档案。新隐私窗口适合演示首次体验。
- **资源连接：** Panda Data / QuantSkills 链接是后续研究资源入口，不代表已自动安装、执行或获得服务权限。

## 6. 检查方式与常见问题

如需检查代码规则，额外准备 Node.js，在项目根目录运行：

```sh
node scripts/test.cjs
```

脚本覆盖推荐分流、调查预算、提示与重复隔离、时间顺序、计算成本等规则。以实际运行输出和退出状态为准；自动检查不能代替浏览器试玩或真实用户测试。

| 现象 | 处理方式 |
| --- | --- |
| 提示找不到 `python3`、`py` 或 `python` | 先安装 Python 3，重新打开终端，使用该电脑可用的 Python 3 命令。 |
| 提示找不到 `scripts/serve.py` | 当前目录不对；进入同时含 `dist` 和 `scripts` 的项目目录。不要只解压或移动部分文件。 |
| 8765 端口被占用 | 关闭此前本项目服务，或运行 `python3 scripts/serve.py --port 8766`；Windows 对应 `py -3 scripts/serve.py --port 8766`，再打开 `http://127.0.0.1:8766/`。 |
| 页面打不开 | 确认启动终端仍在运行，地址使用 `http` 和相同端口；不要输入 `https`。 |
| 字体与截图略有不同 | 可能是 Google Fonts 未加载，系统字体回退不影响核心功能。 |
| 动画较少或未自动播放 | 可点击播放或重播；系统“减少动态效果”设置也可能减少运动表现。 |
| 页面仍显示旧版，或提示已玩过 | 刷新页面；需要首次体验时使用新隐私窗口，或清除此地址的网站数据。清理前先导出要保留的档案。 |
| 没有真实行情或登录入口 | 这是可离线试玩的合成数据分发版，属于预期行为。 |
