# 交易物种：圣杯拍卖会 · v4.1
帮助量化平台首次访问者完成适合自己的第一次研究。三关游戏收集行为依据，形成可解释画像，分流到带练、验证或自主任务，再根据任务表现调整下一步。

## 运行
静态演示：本目录执行 `python3 -m http.server 8765 --directory dist`。无前端依赖；线上私有版使用合成数据。
本机真实版：工作区 `.panda-private/server.py` 运行于 http://127.0.0.1:8765/ 。账号、原始行情及本机认证辅助程序不包含在本仓库与部署包中。主页“连接数据”可取数；HTTP 网关按用户选择使用，有传输风险提示。

## v4 新主线：圣杯拍卖会

三份脚本角色提案、按证据封存判断、最终揭晓。零基础带练每份提供三枚调查币与白话解释；独立挑战三份共用三枚币。故意读取未来、样本复用与有限合规观察构成三种教学报告，数字由当前数据计算。不同报告口径不同，不按收益排名。

记录查看过的底稿、选择依据、自信、提示与重复练习；未查看的知识保持未知。后续任务匹配时间、样本或结论边界，搭档带练与自主模式可选。原远征作为次入口保留。

[产品审查、官方参考与五个创意方向](docs/product-review.html)。审查截图及授权样本只保留本机。

## v4.1 零基础入口

打开页面即静音播放 20 秒开场（系统减少动态偏好除外，数据连接深链不抢占）。从饼干试吃的小练习学会“听他说—找证据—作决定”，再进入提案。支持直接开始带练和主动选择独立挑战。

每位角色有自己的调查问句；决定按钮附白话含义；换关显示上一份封存、当前角色、清空选择与币补充。小白手册随时打开，包含术语和规则。带练全部标记 assisted，不计独立能力，重复练习也不会恢复独立测评资格。

## 原远征已实现
迷雾岔路：两币三张情报，试探/观察/绕路选择。
反转风暴：真实或合成行情分两段揭晓，保持/调整/复核改变仓位状态与笔记，记录可见截止时间。
策略修理铺：三工具和三故障槽位一一匹配，可移动和诊断，分别记录首次独立完成、重试和提示。
结果：四种趣味物种、可回看证据、重走分支对比、可修改探索偏好、三种研究任务；保留研究计算、完成反馈、JSON/CSV/SVG 导出和开场动画。

## 真实数据
本机用 panda_data 1.0.5 的 get_stock_daily 获取 000001.SZ，查询 20250101—20250131，返回 18 个交易日（20250102—20250127）。真实数据已进入本机游戏、量能线索与实验。复权口径待核对，样本较短。授权行情未上传站点；静态版为 40 点合成数据，来源标签明确。

## 推荐规则
首次无提示一次完整修复 → 本次独立操作证据；自主偏好推荐 independent，否则 validation。反馈或提示后完成 → guided，不推断低能力。预算、收益和是否观望不参与知识判断。
查样本 + 风暴复核 + 完成修理 → 证据狐狸；试探且保持 → 信号猎豹；观察/绕路且保持 → 耐心大象；其余迁徙候鸟。按顺序判定，是趣味行为表达，不是心理测量。
查样本 + 复核 + 首次独立修复三条一致才为中等充分度，其他有限。用户可重走并比较前后物种和任务，原始过程可导出。提示与学习表现分别记录。
风暴结束已看过全段，后续实验明确提示不能再称为未见样本。浏览器源数据可检查，体验封存不是安全防作弊。

## 计算口径
前 min(20,floor(N*2/3)) 个点为探索，至少 10 点。前日收盘与更早 n 日均值比较，下一日开盘调整 0/1 仓位，按开盘到次日开盘计收益。单边变化成本 0.1%，最后开盘退出计费。持有基准同区间同成本。回撤按日频净值估算。无滑点、停牌、涨跌停与成交限制模拟，不是生产回测。浏览器封存是体验隔离，不是防作弊隔离。
